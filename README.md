# 🦟 Malaria Early Warning & Prevention System

An interactive, data-driven public health intelligence dashboard designed to monitor vector-borne malaria risk across high-density zones in Oyo State (Ibadan & Ogbomoso).

🔗 **Live App:** [Click Here to View Live App]((https://malaria-early-warning-system.streamlit.app/))

---

## 📌 Project Overview
Malaria transmission is heavily driven by environmental and micro-climatic factors such as temperature, relative humidity, and precipitation. This platform provides public health officers and field teams with real-time risk modeling to transition from reactive response to proactive intervention.

---

## ✨ Key Features
* **Real-Time Weather Integration:** Pulls live meteorological data via the Open-Meteo API for target zones.
* **Spatial Risk Mapping:** Interactive map visualization pinpointing risk levels across monitored locations.
* **Zone Deep-Dive Inspector:** Detailed neighborhood-level metrics, environmental indicators, and tailored emergency guidance.
* **Actionable Data Export:** One-click CSV export functionality enabling field logistics teams to dispatch resources immediately.

---

## 🛠️ Built With
* **Python 3.13**
* **Streamlit** (UI Framework)
* **Pandas** (Data Manipulation & Analytics)
* **Open-Meteo API** (Live Weather Data)
